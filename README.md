# Протокол созвона

Видео или аудио → FFmpeg → локальный Whisper → `codex` / `gpt-6-sol` → **один `.md`**.

В файле: саммари, решения, задачи по участникам с чекбоксами, сроками и цитатами-основаниями,
открытые вопросы и полная транскрипция с таймкодами.

## Запуск

Дважды нажми `start.command` в Finder или выполни в этой папке:

```sh
uv run streamlit run app.py
```

Открой http://127.0.0.1:8501, загрузи запись, при желании укажи имена участников,
их роли и дату созвона, нажми **«Собрать протокол»**. Скачай Markdown кнопкой.
Файл также сохраняется в `data/results/`.
Для файлов больше 2 ГБ используй вкладку **«Файл на компьютере»** и полный путь.
Остановить сервер: Ctrl+C в терминале.

Без браузера:

```sh
uv run python -m calls '/путь/созвон.mp4' \
  --title 'Планирование' \
  --context 'Дата: 29.09.2026. Анна — дизайн, Илья — разработка.'
```

## Как устроено

- Whisper `small` работает на CPU в int8. `medium` и `large-v3` можно выбрать в настройках:
  качество и требования к ресурсам отличаются; скорость зависит от компьютера и записи.
- Модель загружается один раз в `data/models/`, затем распознавание работает локально.
  FFmpeg поставляется Python-пакетом, Homebrew-установка не нужна.
- В Codex отправляются **текст транскрипции и введённый контекст**, видео и звук остаются локально.
  Нужны интернет и авторизация в Codex; отдельный API-ключ не нужен.
  Использование модели учитывается в лимитах этого профиля.
- По умолчанию запускается обычный `codex` с его стандартной авторизацией
  (в том числе с унаследованным `CODEX_HOME`, если он задан).
  Пользовательские настройки Codex, плагины, hooks и MCP не загружаются.
  Модель явно задаётся как `gpt-6-sol`; её можно поменять в интерфейсе.
  `CALLS_CODEX_HOME` позволяет явно переопределить каталог авторизации.
- Длинные записи разбиваются на текстовые фрагменты, затем заметки объединяются.
  Полная исходная транскрипция добавляется в результат кодом без сокращения.
- Промежуточные транскрипции и ответы лежат в `data/cache/`: при повторном запуске
  после ошибки готовые этапы используются снова. Другие участники/модель вызывают новое саммари.
  Временное извлечённое аудио удаляется после распознавания; исходный файл не меняется.
- Имена говорящих **не определяются по голосу**. Задачи назначаются по явным формулировкам;
  неопределённые исполнители — «Уточнить», отсутствующие сроки — «Не указан».
  Фраза «я сделаю» без установленного говорящего не доказывает исполнителя.
  Шум, перебивания и неявные договорённости могут приводить к ошибкам: проверяй цитаты.
- Сервер слушает только `127.0.0.1`. Закрытие браузера не заменяет остановку сервера.
  `data/` содержит записи текста и результаты; папка исключена из Git.

## Установка на другой компьютер

Нужны Python 3.12+, `uv`, Codex CLI с поддержкой используемых флагов (проверено на 0.158.0)
и авторизация через `codex login`.

```sh
uv sync --locked
codex login
./start.command
```

Для другого аккаунта с отличающимся набором моделей измени модель в настройках.
При ошибке Codex проверь `codex login status`.
При ошибке загрузки Whisper проверь доступ к Hugging Face и повтори запуск.

## Рабочий алиас (необязательно)

В «Тонкой настройке» есть поле **«Команда или рабочий алиас»**: по умолчанию `codex`,
можно указать `codex-s` или путь к исполняемому wrapper-скрипту.
Алиас должен уже существовать в твоём zsh (`~/.zshrc`) или bash (`~/.bashrc`). Например:

```sh
alias codex-s='CODEX_HOME="$HOME/.codex-s" codex'
```

Приложение запускает алиас через интерактивный `$SHELL` (zsh или bash), который читает
свой startup-файл. Для обычного исполняемого файла shell не используется.
Вводится только имя команды/алиаса или путь, без аргументов и shell-выражений.
Алиас может переопределять `CODEX_HOME`; не сочетай его с конфликтующим `CALLS_CODEX_HOME`.

Чтобы сохранить выбор на своём компьютере, скопируй `settings.example.toml`
в `settings.local.toml` и укажи:

```toml
[codex]
command = "codex-s"
```

`settings.local.toml` исключён из Git: у других пользователей по умолчанию остаётся `codex`.
Также можно задать `CALLS_CODEX_COMMAND=codex-s` при запуске приложения.
Приоритет: поле интерфейса / флаг CLI → переменная окружения → локальный файл → `codex`.

```sh
uv run python -m calls '/путь/созвон.mp4' --codex-command codex-s
```
